## 실행

```powershell
cd C:\Users\ong07\allcheck\capstone\apps\driver
npm.cmd run dev
```

- PC: http://localhost:5174
- Android 에뮬레이터 Chrome: http://10.0.2.2:5174
- 휴대폰 웹: PC와 같은 네트워크에서 `http://PC의IP:5174` (방화벽 허용 필요)
- Android Studio: 이 폴더의 `android/`를 별도 프로젝트로 엽니다.
- APK: `android/app/build/outputs/apk/debug/allcheck-driver-debug.apk`
- 설치 이름: **올체크 기사**, 패키지: `kr.allcheck.driver`

`카카오로 시작하기`는 카카오 인증 대신 테스트 회원가입으로 연결됩니다. `기사 화면 보기`은 승인 상태의 가상 계정으로 진입하는 테스트 버튼입니다. 실제 개인정보·계좌번호·고객 사진을 입력하지 마세요.

## 저장 및 연결 경계

- 현재 데이터는 `allcheck-driver-ver2-v1` 키로 각 브라우저/앱의 localStorage에 저장됩니다. PC, 관리자앱, 기사앱 간 데이터는 공유되지 않습니다.
- 사진은 보고서에 data URL로 저장합니다. 항목별 최대 3장, 장당 3MB를 허용합니다. 기기 저장 용량을 초과하면 저장 실패를 안내하고 기존 저장 상태를 유지합니다. 실제 서비스에서는 서버 파일 업로드·별도 파일 저장으로 교체해야 합니다.
- 카카오 인증, 사업자 실재 조회, 관리자 승인·반려/푸시, 실제 배차 수신·수락 경쟁, 서버 보고서 제출, 실시간 채팅은 모의 동작 또는 연결 전입니다. 화면의 테스트 안내와 로컬 상태가 실제 보안 권한 검증을 대신하지 않습니다.
- 위치는 사용자가 버튼을 눌렀을 때 권한을 받아 1회 확인합니다. 위치 좌표를 저장하거나 서버에 보내지 않습니다. 백그라운드 위치 수집은 구현하지 않았습니다. 웹 위치 확인은 HTTPS 또는 localhost 등 보안 컨텍스트가 필요합니다.
- 지도·고객 전화는 실제 연결하지 않습니다. 테스트 고객 연락처는 가상 번호입니다.
- 사진 추가는 Android 시스템 선택창을 사용하며 전체 사진/저장소 권한은 요청하지 않습니다.
- 약관/개인정보 안내는 테스트용 안내문이며 실제 서비스 문서가 아닙니다.
- 백엔드·AI 파일은 수정하지 않았습니다. 코드 커밋·푸시, 기사웹 외부 배포는 하지 않았습니다.

- 실제 휴대폰 GPS 및 각 제조사별 사진 선택은 추가 검증 필요

## 빌드

JDK 17과 Android SDK 36을 준비한 뒤:

```powershell
npm.cmd run android:build
```

Android Studio 기본 Java가 25라면 Gradle 8.13과 호환되는 JDK 17을 Gradle JDK로 선택해야 합니다. 필요하면 `android/local.properties`에 SDK 경로를 설정합니다. 이 파일과 APK/build 결과는 Git에서 제외됩니다. 기기에서 확인할 때는 기존 관리자앱과 별도로 기사앱을 실행하세요.
