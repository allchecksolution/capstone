# 올체크 관리자 프로토타입

Figma 관리자 와이어프레임을 기준으로 만든 반응형 프런트엔드입니다. 외부 패키지 설치 없이 Node.js로 실행합니다.

```powershell
cd C:\Users\ong07\allcheck\capstone\apps\admin
npm.cmd run dev
```

PC: http://localhost:5173

Android Studio 에뮬레이터의 Chrome: http://10.0.2.2:5173

- 원하는 임시 아이디/비밀번호 → 테스트 인증 코드 `123456` → 홈
- 최초 데이터는 0건입니다. 의뢰를 등록하면 목록·상세·통계에 반영됩니다.
- 기간/유형/상태 필터, 검색, CSV 내보내기, 의뢰 취소, 알림 설정을 제공합니다.
- 데이터는 현재 브라우저의 localStorage에만 저장됩니다. 실제 고객 정보는 입력하지 마세요.
- 로그아웃 후에도 의뢰 내역은 유지됩니다. 페이지를 새로 열면 로그인부터 시작합니다.
- 로그인/MFA는 모의 흐름이며 보안 인증이 아닙니다. API, 기사 배차, 상담 수신, 채팅, 푸시 알림은 연결되지 않았습니다.
- Figma 아이콘 파일 다운로드가 네트워크 제한으로 차단되어 탐색 메뉴는 텍스트로 표시합니다. 아이콘 일치 검증과 브라우저 시각 검증은 미완료입니다.

서버는 에뮬레이터 접근을 위해 `0.0.0.0:5173`에 바인딩됩니다. 종료하려면 실행한 터미널에서 Ctrl+C를 누르세요.

Android app: [build and install instructions](android/README.md).

## 흐름 대조 보완 (v0.2.0)

관리자·기사의 기존 화면과 ver2 대조 및 구현/연동 경계는 [프론트 흐름 대조표](../FRONTEND_FLOW_AUDIT.md)를 참고하세요. 접수 검토·배차 전달 상태·기사 심사·보고서 원본/수정 이력·취소 후속 처리·채팅 및 CSV/XLSX 내보내기를 로컬 상태로 확인할 수 있습니다. 실제 서버 전송은 연결 전입니다.
