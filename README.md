# Capstone

이 저장소는 팀의 요구사항, 화면 설계, 코드와 작업 기록을 함께 관리하는 공간입니다.

## 처음 참여할 때

1. 저장소에 접근할 수 있는지 확인하고, [팀 사용설명서](docs/TEAM_GUIDE.md)를 읽습니다.
2. [공통 자료 목록](docs/resources.md)에서 최신 문서와 원본 자료의 위치를 확인합니다.
3. 작업할 내용을 Issue로 정리한 뒤, `main`에서 새 브랜치를 만들어 진행합니다.
4. 작업이 끝나면 Pull Request를 열어 팀원 검토 후 `main`에 합칩니다.

## 공통 문서

| 문서 | 용도 |
| --- | --- |
| [팀 사용설명서](docs/TEAM_GUIDE.md) | 저장소 사용, 브랜치, Pull Request 절차 |
| [공통 자료 목록](docs/resources.md) | 모두가 참조할 자료의 공식 위치 |
| [요구사항](docs/requirements.md) | 합의한 기능과 변경 기록 |
| [화면 설계](docs/screen-design.md) | 화면별 목적과 설계 자료 링크 |

프로젝트의 구체적인 내용은 팀이 합의하면서 위 문서에 채워 넣습니다. 문서도 코드와 같은 브랜치 및 Pull Request 절차로 수정합니다.
