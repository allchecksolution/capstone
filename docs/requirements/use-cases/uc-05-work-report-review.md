# UC-05 작업 보고서 검토 및 수정

| 항목           | 내용                                                                                                                                                                                        |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                                                       |
| **유스케이스 내용** | 관리자가 기사가 제출한 작업 보고서와 작업 결과를 확인하고 필요한 경우 수정한다.                                                                                                                                             |
| **사전 조건**    | 1. 관리자가 로그인되어 있어야 한다.<br>2. 기사가 작업 보고서를 등록한 상태여야 한다.                                                                                                                                      |
| **기본 흐름**    | 1. 관리자가 작업 보고서 목록을 조회한다.<br>2. 관리자가 확인할 작업 보고서를 선택한다.<br>3. 시스템이 작업 전·후 사진, 작업 내용, 비용 등 보고서 정보를 표시한다.<br>4. 관리자가 작업 결과를 확인한다.<br>5. 필요한 경우 관리자가 수정 가능한 정보를 수정한다.<br>6. 시스템이 수정된 정보를 저장한다. |
| **예외 흐름**    | E1. 작업 보고서가 아직 등록되지 않은 경우 → 시스템이 미등록 상태를 표시한다.<br>E2. 보고서 수정 또는 저장에 실패한 경우 → 시스템이 오류를 안내한다.                                                                                               |
| **대안 흐름**    | A1. 수정할 내용이 없는 경우 → 관리자는 조회만 수행하고 종료한다.                                                                                                                                                   |
| **사후 조건**    | 관리자가 작업 결과를 확인하며, 수정한 경우 변경된 보고서 정보가 저장된다.                                                                                                                                                |
