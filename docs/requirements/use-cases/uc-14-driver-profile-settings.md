# UC-14 기사 개인정보 및 환경 설정 관리

| 항목           | 내용                                                                                                                                                                                         |
|--------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                         |
| **유스케이스 내용** | 기사가 자신의 개인정보와 전문 분야, 활동 지역, 보유 장비 등 서비스 이용에 필요한 환경 설정을 등록하거나 수정한다.                                                                                                                         |
| **사전 조건**    | 1. 기사가 로그인되어 있어야 한다.<br>2. 기사 계정이 등록되어 있어야 한다.                                                                                                                                             |
| **기본 흐름**    | 1. 기사가 개인정보 및 환경 설정 화면에 진입한다.<br>2. 시스템이 현재 등록된 정보를 표시한다.<br>3. 기사가 수정할 정보를 선택한다.<br>4. 기사가 전문 분야, 활동 지역, 연락처 등의 정보를 입력 또는 수정한다.<br>5. 기사가 변경사항을 저장한다.<br>6. 시스템이 입력된 정보를 확인하고 변경사항을 저장한다. |
| **예외 흐름**    | E1. 필수 정보가 누락된 경우 → 시스템이 누락 항목을 안내한다.<br>E2. 올바르지 않은 형식의 정보가 입력된 경우 → 시스템이 수정을 요청한다<br>E3. 정보 저장에 실패한 경우 → 시스템이 오류를 안내한다.                                                                  |
| **대안 흐름**    | A1. 알림 설정 기능을 제공하는 경우 → 기사가 배차 요청 등의 알림 수신 여부를 설정한다.                                                                                                                                       |
| **사후 조건**    | 변경된 기사 정보 및 환경 설정이 저장되고 전문 분야와 활동 지역 등 배차 관련 정보가 이후 배차에 반영된다.                                                                                                                              |
