# UC-06 기사 가입 승인 및 반려

| 항목           | 내용                                                                                                                                                                                                                                                             |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                                                                                                                            |
| **유스케이스 내용** | 관리자가 가입 신청한 기사의 기본 정보, 사업자 정보 및 활동 정보를 확인하고 최종 가입 승인 또는 반려를 결정한다.                                                                                                                                                                                              |
| **사전 조건**    | 1. 관리자가 로그인되어 있어야 한다.<br>2. 기사 회원정보가 등록되어 있어야 한다.<br>3. 해당 기사의 사업자 검증 결과가 성공이어야 한다.<br>4. 해당 기사 계정 상태가 '승인 대기'여야 한다.                                                                                                                                                                                                              |
| **기본 흐름**    | 1. 관리자가 승인 대기 상태를 포함한 기사 목록을 조회한다.<br>2. 관리자가 특정 기사를 선택한다.<br>3. 시스템이 기사의 기본 정보, 사업자 정보, 전문 분야, 활동 지역, 보유 장비 및 사업자 검증 결과를 표시한다.<br>4. 관리자가 등록된 정보를 확인한다.<br>5. 관리자가 가입 승인을 선택한다.<br>6. 시스템이 승인 처리 시점에 사업자 검증 성공과 계정의 '승인 대기' 상태를 다시 확인하고, 두 조건을 모두 충족한 경우에만 '활성'으로 변경한다. 하나라도 충족하지 못하면 승인을 거부하고 계정 상태를 변경하지 않으며 사유를 안내한다.<br>7. 시스템이 기사에게 가입 승인 결과를 알린다. |
| **예외 흐름**    | E1. 기사 정보가 누락된 경우 → 시스템이 미등록 또는 미완성 항목을 표시한다.<br>E2. 이미 승인 또는 반려 처리된 신청을 다시 처리하려는 경우 → 시스템이 재처리를 제한한다                                                                                                                                                          |
| **대안 흐름**    | A1. 관리자가 이름, 사업체명 등의 조건으로 기사를 검색하여 조회한다.<br>A2. 관리자가 가입을 반려하는 경우 → 관리자가 반려 사유를 입력하고, 시스템이 계정 상태를 '반려'로 변경한 뒤 기사에게 반려 사유를 통보한다.                                                                                                                                 |
| **사후 조건**    | 승인된 경우 기사 계정이 활성화되어 정상적으로 서비스를 이용할 수 있고, 반려된 경우 계정은 비활성 상태로 유지되며 기사에게 반려 사유가 통보된다.                                                                                                                                                                             |
