# UC-07 배차 취소 요청 검토 및 재배차

| 항목           | 내용                                                                                                                                                                                                                    |
|--------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                                                                                   |
| **유스케이스 내용** | 관리자가 기사가 제출한 배차 취소 요청을 검토하고 해당 의뢰에 대한 재배차를 진행한다.                                                                                                                                                                      |
| **사전 조건**    | 1. 관리자가 로그인되어 있어야 한다.<br>2. 기사가 제출한 배차 취소 요청[UC-14](./uc-14-dispatch-cancellation-request.md)이 존재해야 한다.                                                                                                               |
| **기본 흐름**    | 1. 관리자가 배차 취소 요청 목록을 조회한다.<br>2. 관리자가 취소 사유와 의뢰 정보를 확인한다.<br>3. 관리자가 재배차를 진행하기로 결정한다.<br>4. 시스템이 기존 배차·취소 이력은 유지한 채 해당 의뢰를 재배차 대상 상태로 전환한다.<br>5. 시스템이 출동 가능한 기사 후보를 다시 선별하여 배차 요청을 전달한다.<br>6. 관리자가 재배차 진행 상태를 확인한다. |
| **예외 흐름**    | E1. 재배차 가능한 기사 후보가 없는 경우 → 시스템이 관리자에게 안내하고 수동 처리를 요청한다.<br>E2. 이미 다른 방식으로 종료 처리된 취소 요청인 경우 → 시스템이 재배차 처리를 제한한다.                                                                                                       |
| **대안 흐름**    | A1. 관리자가 재배차 대신 의뢰 자체를 취소하기로 결정하는 경우 → 시스템이 의뢰를 취소 상태로 종료한다.                                                                                                                                                          |
| **사후 조건**    | 재배차가 시작되면 새로운 배차 절차가 진행되고, 기존 취소 이력은 그대로 보존된다.                                                                                                                                                                        |
