# UC-04 의뢰 현황 및 통계 조회

| 항목                 | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **행위자**           | 관리자                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **유스케이스 내용**  | 관리자가 하나의 화면에서 진행 중인 의뢰와 과거 완료·취소된 의뢰를 조건별로 조회하고, 의뢰별 배차·재배차 이력과 조회 기간의 통계를 확인한다.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **사전 조건**        | 1. 관리자가 로그인되어 있어야 한다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **기본 흐름**        | 1. 관리자가 의뢰 현황 및 통계 화면에 진입한다.<br>2. 시스템이 의뢰 목록과 현재 진행 상태, 통계 정보를 표시한다.<br>3. 관리자가 조회 기간과 검색·필터 조건(상태, 작업 유형, 기사, 지역)을 필요에 따라 설정한다.<br>4. 시스템이 설정된 조건에 해당하는 의뢰 목록과 해당 기간의 통계를 함께 표시한다.<br>5. 관리자가 특정 의뢰를 선택한다.<br>6. 시스템이 해당 의뢰의 접수 정보, 작업 유형, 현재 배차 상태, 배정 기사 및 최신 작업 진행 상태를 표시한다.<br>7. 관리자가 최초 배차부터 재배차까지 단계별 배정 기사와 배차 취소·배정 해제 이력을 현재 배차 상태와 구분하여 확인한다. |
| **예외 흐름**        | E1. 선택한 의뢰를 찾을 수 없는 경우 → 시스템이 해당 의뢰를 찾을 수 없음을 안내한다.<br>E2. 설정된 조건에 해당하는 의뢰가 없는 경우 → 시스템이 조회 결과가 없음을 표시한다. 조회할 데이터가 없어도 화면에는 접근할 수 있다.<br>E3. 설정된 기간에 통계 데이터가 없는 경우 → 시스템이 해당 기간의 통계 데이터가 없음을 표시한다.<br>E4. 목록·통계·상세 조회에 실패한 경우 → 시스템이 오류를 안내한다.                                                                                                                                                                              |
| **대안 흐름**        | A1. 배차 진행에 이상이 있는 의뢰를 조회하는 경우 → 시스템이 [UC-03](./uc-03-dispatch-request.md)의 후보 미확보·전체 전달 실패를 정상적인 배차 진행과 구분하여 표시하고, 일부 전달 실패는 기사별 전달 결과와 정상 전달된 기사에 대한 배차 진행 상황을 함께 표시한다. 푸시 발행 또는 전달 서비스의 접수 성공을 기사의 실제 수신·확인 성공으로 표시하지 않는다.<br>A2. 데이터 내보내기 기능을 제공하는 경우 → 관리자가 조회 결과를 스프레드시트 등 외부 형식으로 내보낸다.                                                                                                         |
| **사후 조건**        | 기존 의뢰 데이터는 변경되지 않으며, 관리자는 진행 중·과거 의뢰, 배차·재배차 이력과 조회 기간의 통계를 확인한다. 과거 배차 및 취소 이력은 [FR-12](../functional-requirements/fr-12-dispatch-cancellation-and-redispatch-management.md)에 따라 보존되며 이후 재배차로 사라지거나 현재 배차 정보로 덮어써지지 않는다. 최신 배차 및 작업 진행 상태는 [FR-09](../functional-requirements/fr-09-request-and-work-status-management.md)에 따라 실시간으로 반영된다.                                                                                                                    |
| **설계 시 고려사항** | 필터 UI·API 구현 방식, 지역 세부 분류 체계, 통계 지표·계산 방식·집계 주기·집계 기준, 필터와 통계 집계의 연동 여부는 추후 결정한다. 작업 보고서 기반 조회·통계는 [FR-11](../functional-requirements/fr-11-work-report-registration-and-management.md)의 최신 유효 수정 내용 반영 및 중복 방지 기준을, 기사 탈퇴 관련 데이터는 [UC-15](./uc-15-driver-account-withdrawal.md)의 접근 통제 및 보존·파기 정책을 따른다.                                                                                                                                                              |
