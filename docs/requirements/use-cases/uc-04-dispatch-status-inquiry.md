# UC-04 작업 현황 및 통계 조회

| 항목           | 내용                                                                                                                                                                                                                                                                                  |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자** | 관리자 |
| **유스케이스 내용** | 관리자가 하나의 화면에서 진행 중인 의뢰 및 작업과 과거 완료·취소된 의뢰 및 작업을 조건별로 조회하고, 배차·재배차 이력과 설정된 조회 기간의 통계 정보를 확인한다. |
| **사전 조건** | 관리자가 로그인되어 있어야 한다. 조회할 의뢰 또는 작업 데이터가 없는 경우에도 화면에 접근할 수 있어야 한다. |
| **기본 흐름** | 1. 관리자가 작업 현황 및 통계 화면에 진입한다.<br>2. 시스템이 등록된 의뢰 및 작업 목록의 현재 상태와 통계 정보를 표시한다.<br>3. 관리자가 조회 기간과 검색 및 필터링 조건을 설정한다.<br>4. 시스템이 설정된 조건에 해당하는 의뢰 및 작업 목록을 표시한다.<br>5. 시스템이 설정된 조회 기간에 해당하는 통계 정보를 표시한다.<br>6. 관리자가 특정 의뢰 또는 작업을 선택한다.<br>7. 시스템이 해당 의뢰의 접수 정보, 작업 유형, 현재 배차 상태, 배정 기사, 최신 작업 진행 상태 및 관련 이력을 표시한다.<br>8. 관리자가 해당 의뢰의 최초 배차부터 이후 재배차까지 각 단계의 배정 기사와 배차 취소·배정 해제 이력을 현재 배차 상태와 구분하여 조회한다.<br>9. 관리자가 작업 현황, 과거 작업 이력 및 통계 정보를 확인한다. |
| **검색 및 필터링 조건** | 조회 기간, 작업 상태, 작업 유형, 기사 및 지역 조건을 필요에 따라 조합하여 의뢰 및 작업 목록을 조회할 수 있어야 한다. 설정된 기간에 해당하는 데이터를 조회하며, 진행 중·완료·취소 및 기타 기존 요구사항에 정의된 의뢰·작업 상태를 조건으로 현재 작업과 과거 종료된 작업을 구분하여 조회한다. 작업 유형은 기존 요구사항의 정의를 따르고, 특정 기사 또는 지역과 관련된 의뢰 및 작업을 조회할 수 있어야 한다. |
| **배차 진행 및 전달 결과** | [UC-03](./uc-03-dispatch-request.md)의 후보 미확보·전체 전달 실패는 정상적인 배차 진행과 구분하여 표시한다. 일부 전달 실패는 기사별 전달 결과와 정상 전달된 기사에 대한 배차 진행 상황을 함께 표시한다. 푸시 발행 또는 전달 서비스의 접수 성공을 기사의 실제 수신·확인 성공으로 표시하지 않는다. |
| **통계 정보** | 통계는 관리자가 설정한 조회 기간을 기준으로 표시하고, 조회 기간이 변경되면 해당 기간의 통계 정보를 조회하여 표시한다. 작업 보고서 기반 조회·통계에는 [FR-11](../functional-requirements/fr-11-work-report-registration-and-management.md)의 최신 유효 수정 내용 반영 및 중복 방지 기준을 적용한다. |
| **예외 흐름** | E1. 조회하려는 특정 의뢰 또는 작업이 존재하지 않는 경우 → 시스템이 해당 의뢰 또는 작업을 찾을 수 없음을 안내한다.<br>E2. 설정된 조회 조건에 해당하는 의뢰 및 작업 데이터가 없는 경우 → 시스템이 조회 결과가 없음을 표시한다.<br>E3. 설정된 조회 기간에 통계 데이터가 없는 경우 → 시스템이 해당 기간의 통계 데이터가 없음을 표시한다. |
| **대안 흐름** | A1. 관리자가 조회 기간 또는 필터 조건을 변경하는 경우 → 시스템이 변경된 조건에 따라 작업 목록을 다시 조회하고, 조회 기간이 변경되면 해당 기간의 통계도 다시 표시한다.<br>A2. 관리자가 특정 의뢰의 과거 배차 및 재배차 이력을 확인하는 경우 → 시스템이 [FR-12](../functional-requirements/fr-12-dispatch-cancellation-and-redispatch-management.md)에 따라 보존된 최초 배차·재배차 단계별 배정 기사와 배차 취소·배정 해제 이력을 표시한다. 과거 이력은 이후 재배차로 사라지거나 현재 배차 정보로 덮어써지지 않는다.<br>A3. 데이터 내보내기 기능을 제공하는 경우 → 관리자가 조회 결과를 스프레드시트 등의 외부 형식으로 내보낸다. |
| **사후 조건** | 기존 의뢰 및 작업 데이터는 변경되지 않는다. 관리자는 진행 중인 작업, 과거 작업 이력, 배차 및 재배차 이력과 설정된 조회 기간에 대한 통계 정보를 확인한다. 최신 배차 및 작업 진행 상태는 [FR-09](../functional-requirements/fr-09-request-and-work-status-management.md)에 따라 실시간으로 반영된다. |
| **설계 시 고려사항** | 검색·필터의 구체적인 UI 구성 및 API 구현 방식, 지역 세부 분류 체계는 이번 문서에서 확정하지 않는다. 통계의 구체적인 지표·데이터 항목, 계산 방식·집계 주기·집계 기준 및 작업 목록의 상태·작업 유형·기사·지역 필터와 통계 집계의 연동 여부는 추후 결정한다. |
