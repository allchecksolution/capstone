# UC-04 작업 진행 상태 조회

| 항목           | 내용                                                                                                                                                     |
|--------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                    |
| **유스케이스 내용** | 관리자가 등록된 의뢰의 배차 및 작업 진행 상태를 확인한다.                                                                                                                      |
| **사전 조건**    | 1. 관리자가 로그인되어 있어야 한다.<br>2. 조회할 의뢰가 등록되어 있어야 한다.                                                                                                       |
| **기본 흐름**    | 1. 관리자가 의뢰 목록을 조회한다.<br>2. 시스템이 각 의뢰의 현재 상태를 표시한다.<br>3. 관리자가 특정 의뢰를 선택한다.<br>4. 시스템이 접수 정보, 배차 상태, 배정 기사 및 작업 진행 상태를 표시한다. [UC-03](./uc-03-dispatch-request.md)의 후보 미확보·전체 전달 실패는 정상적인 배차 진행과 구분하고, 일부 전달 실패는 기사별 전달 결과와 정상 전달된 기사에 대한 배차 진행 상황을 함께 표시한다. 푸시 발행 또는 전달 서비스의 접수 성공을 기사의 실제 수신·확인 성공으로 표시하지 않는다.<br>5. 관리자가 현재 진행 상황을 확인한다. |
| **예외 흐름**    | E1. 조회하려는 의뢰가 존재하지 않는 경우 → 시스템이 해당 의뢰를 찾을 수 없음을 안내한다.                                                                                                  |
| **대안 흐름**    | A1. 관리자가 상태 또는 기간 등의 검색 조건을 지정하여 의뢰 목록을 조회한다.                                                                                                          |
| **사후 조건**    | 의뢰 정보의 변경 없이 관리자가 현재 진행 상태를 확인한다.                                                                                                                      |
