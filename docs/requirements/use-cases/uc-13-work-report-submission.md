# UC-13 작업 보고서 등록

| 항목           | 내용                                                                                                                                                                                                                                  |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                                                                  |
| **유스케이스 내용** | 기사가 수행한 작업의 내용과 결과를 작업 보고서로 등록한다.                                                                                                                                                                                                   |
| **사전 조건**    | 1. 기사가 로그인되어 있어야 한다.<br>2. 기사에게 배정된 작업이 존재해야 한다.                                                                                                                                                                                    |
| **기본 흐름**    | 1. 기사가 작업 보고서 작성 화면에 진입한다.<br>2. 기사가 작업 전·후 사진을 등록한다.<br>3. 기사가 작업 내용, 진단 결과, 작업 비용 등 필요한 정보를 입력한다.<br>4. 기사가 작업 보고서를 제출한다.<br>5. 시스템이 입력된 정보를 확인한다.<br>6. 시스템이 작업 보고서를 해당 의뢰에 연결하여 저장한다.<br>7. 등록된 작업 보고서를 관리자가 조회할 수 있는 상태로 변경한다. |
| **예외 흐름**    | E1. 필수 항목이 누락된 경우 → 시스템이 누락된 정보를 안내한다.<br>E2. 사진 등록에 실패한 경우 → 시스템이 재등록을 요청한다.<br>E3. 보고서 저장에 실패한 경우 → 시스템이 오류를 안내한다.                                                                                                                |
| **대안 흐름**    | A1. 임시 저장 기능을 제공하는 경우 → 기사가 작성 중인 보고서를 임시 저장하고 이후 작성을 계속한다.                                                                                                                                                                         |
| **사후 조건**    | 작업 보고서가 해당 의뢰 및 작업 이력에 저장되고 관리자가 조회할 수 있다.                                                                                                                                                                                          |
