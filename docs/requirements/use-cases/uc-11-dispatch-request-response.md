# UC-11 배차 요청 수락 및 거절

| 항목           | 내용                                                                                                                                                                                                                |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                                                |
| **유스케이스 내용** | 기사가 전달받은 배차 요청을 확인한 후 수락하거나 거절한다.                                                                                                                                                                                 |
| **사전 조건**    | 1. 기사가 로그인되어 있어야 한다.<br>2. 유효한 배차 요청이 기사에게 전달되어 있어야 한다.                                                                                                                                                           |
| **기본 흐름**    | 1. 배차 요청 알림이 전송된다. (ex.카카오택시)<br>2. 기사가 배차 요청 상세정보를 확인한다.<br>3. 기사가 `수락`을 선택한다.<br>4. 시스템이 해당 배차 요청의 유효성을 확인한다.<br>5. 시스템이 해당 기사를 의뢰의 담당 기사로 확정한다.<br>6. 시스템이 기사에게 배차 확정 결과를 표시한다.<br>7. 관리자 화면에 변경된 배차 상태가 반영된다. |
| **예외 흐름**    | E1. 다른 기사가 먼저 해당 의뢰를 수락한 경우 → 시스템이 해당 요청이 이미 마감되었음을 안내한다.<br>E2. 배차 요청의 유효시간이 만료된 경우 → 시스템이 수락할 수 없음을 안내한다<br>E3. 처리 중 오류가 발생한 경우 → 시스템이 수락 실패를 안내한다.                                                             |
| **대안 흐름**    | A1. 기사가 `거절`을 선택하는 경우 → 시스템이 거절 결과를 저장하고 해당 기사에 대한 배차 요청을 종료한다.                                                                                                                                                   |
| **사후 조건**    | 수락한 경우 담당 기사가 확정되며, 거절한 경우 해당 기사에 대한 배차 요청이 종료된다.                                                                                                                                                                 |
