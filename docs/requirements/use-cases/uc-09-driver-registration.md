# UC-09 기사 소셜 로그인 및 회원가입

| 항목           | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **유스케이스 내용** | 기사가 카카오 소셜 로그인을 통해 인증하고, 최초 이용 시 기사 기본정보와 사업자 정보를 등록하여 가입을 신청한다. 가입 신청은 관리자의 최종 승인이 완료되어야 서비스를 이용할 수 있다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **사전 조건**    | 1. 기사가 카카오 계정을 보유하고 있어야 한다.<br>2. 서비스에 네트워크 연결이 가능해야 한다.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **기본 흐름**    | 1. 기사가 카카오 로그인을 선택한다.<br>2. 카카오 인증을 통해 사용자 인증을 수행한다.<br>3. 시스템이 기존 기사 계정 존재 여부와 계정 상태(승인 대기·활성·반려·탈퇴)를 확인한다. 기존 계정은 상태에 따라 대안 흐름 또는 예외 흐름을 따른다.<br>4. 신규 사용자인 경우 시스템이 기사정보 입력 화면을 제공한다.<br>5. 기사가 근로자명, 사업체명, 업태, 종목, 대표자명, 전화번호, 이메일, 회사 대표번호, 회사 주소, 세금계산서, 정산계좌, 기사 전문분야, 기사 거주지, 기사 활동지, 보유장비, 차량번호 정보를 입력한다.<br>6. 시스템이 외부 사업자등록정보 서비스(공공api)를 통해 사업자 정보를 검증한다<br>7. 검증에 성공하면 시스템이 기사 계정을 '승인 대기' 상태로 등록하고 관리자에게 신규 가입 승인 요청을 알린다.<br>8. 시스템이 기사에게 "관리자 승인 대기 중" 상태를 안내하며, 승인 완료 전까지는 배차·채팅 등 주요 기능 이용을 제한한다.<br>9. 관리자가 가입 신청을 승인하면(UC-06) 시스템이 기사 계정 상태를 '활성'으로 전환하고 기사에게 승인 결과를 알린다.<br>10. 승인 완료 후 활성 상태의 기사가 정상적으로 서비스를 이용할 수 있다. 로그인 인증 성공과 정상 서비스 접근 권한은 구분한다. |
| **예외 흐름**    | E1. 카카오 인증에 실패한 경우 → 시스템이 로그인 실패를 안내한다.<br>E2. 필수 회원정보가 누락된 경우 → 시스템이 누락 항목을 안내한다.<br>E3. 입력한 사업자 정보가 유효하지 않은 경우 → 시스템이 입력 정보를 확인하도록 안내한다.<br>E4. 외부 사업자등록정보 서비스에 장애가 발생한 경우 → 시스템이 현재 검증이 불가능함을 안내한다.<br>E5. 관리자가 가입 신청을 반려한 경우 → 시스템이 계정 상태를 '반려'로 변경하고 기사에게 반려 사유를 안내한다.<br>E6. 탈퇴한 기사 계정으로 로그인하려는 경우 → 시스템이 로그인을 제한하고 사유를 안내한다. |
| **대안 흐름**    | A1. 기존 가입 기사의 계정이 활성 상태인 경우 → 회원정보 등록 및 사업자 검증 과정을 생략하고 로그인하여 정상 서비스를 이용한다.<br>A2. 승인 대기 중인 기사가 재로그인하는 경우 → 시스템이 현재 승인 대기 상태임을 다시 안내하고 정상 서비스 이용은 계속 제한한다.<br>A3. 반려 상태의 기사가 올바른 로그인 정보로 인증한 경우 → 시스템은 정상 서비스 접근을 제한하고 반려 안내 화면으로 이동하여 가입 반려 사실과 관리자가 입력한 반려 사유를 표시한다. 화면에 다시 신청하기와 로그아웃을 제공한다.<br>A4. 반려 안내 화면에서 다시 신청하기를 선택한 경우 → 기사가 기존 계정의 가입 신청 정보를 다시 작성하거나 수정한다. 재신청 전까지 반려 상태를 유지하며, 기본 흐름의 입력값·사업자 정보 검증 후 재신청을 제출하면 기존 계정을 '승인 대기'로 변경하고 관리자에게 알린다. 동일 기사 계정을 중복 생성하지 않으며, 관리자 승인이 완료되기 전까지 정상 서비스 이용을 제한한다.<br>A5. 반려 안내 화면에서 로그아웃을 선택한 경우 → 시스템이 로그아웃 처리한다. |
| **사후 조건**    | 신규 가입 또는 재신청이 제출되면 계정은 '승인 대기' 상태가 되며 관리자 승인이 완료된 이후에만 정상 서비스에 접근할 수 있다. 반려 기사는 인증 후 반려 사유 확인·재신청·로그아웃을 이용할 수 있으며 재신청 전까지 반려 상태를 유지한다. 재신청은 기존 계정을 활용하고 기존 반려 사유 및 신청·심사 이력을 추적 가능하게 보존한다. |
