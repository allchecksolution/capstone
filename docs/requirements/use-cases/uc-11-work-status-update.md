# UC-11 작업 진행 상태 변경

| 항목           | 내용                                                                                                                                                                                           |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                           |
| **유스케이스 내용** | 배정된 기사가 실제 작업 진행 상황에 따라 작업 상태를 변경한다.                                                                                                                                                         |
| **사전 조건**    | 1. 기사가 로그인되어 있어야 한다.<br>2. 기사에게 배정된 유효한 의뢰가 존재해야 한다.                                                                                                                                         |
| **기본 흐름**    | 1. 기사가 배정된 의뢰를 조회한다.<br>2. 현장 작업을 시작하면서 `작업 시작`을 선택한다.<br>3. 시스템이 해당 기사의 유효한 배정 여부와 현재 상태에서 허용된 상태 전이인지 검증한 뒤 해당 의뢰의 작업 상태를 진행 중으로 변경한다.<br>4. 현장 작업을 마친 후 기사가 `작업 완료` 버튼을 선택한다.<br>5. 시스템이 [UC-12 작업 보고서 등록](./uc-12-work-report-submission.md)의 보고서 작성 화면으로 연결한다. 버튼 선택이나 작성 화면 진입만으로 작업을 완료 처리하지 않는다.<br>6. 기사가 보고서를 작성하고 제출한다.<br>7. 시스템이 제출 시점의 유효 담당자·작업 상태·제출 권한과 입력값을 확인하고, 보고서 최초 제출 저장과 작업 상태의 완료 변경을 원자적으로 처리한다. 이미 정상 처리된 최초 제출의 반복 요청은 UC-12의 중복 처리 기준을 따른다.<br>8. 보고서 제출 성공 후 변경된 작업 완료 상태가 관리자와 기사에게 반영된다. |
| **예외 흐름**    | E1. 기사에게 배정되지 않은 의뢰의 상태 변경을 요청한 경우 → 시스템이 요청을 거부한다.<br>E2. 허용되지 않는 순서로 상태 변경을 요청한 경우 → 시스템이 변경을 제한한다.<br>E3. 상태 변경 처리에 실패한 경우 → 시스템이 오류를 안내한다.<br>E4. [UC-13](./uc-13-dispatch-cancellation-request.md)의 배차 취소 요청이 정상 접수되어 해당 의뢰의 배정에서 해제된 기사가 작업 상태 변경을 요청한 경우 → 시스템이 요청을 거부한다.                                               |
| **대안 흐름**    | A1. 작업이 당일 완료되지 않고 추가 방문이 필요한 경우 → 시스템이 재방문이 필요한 상태로 처리한다.                                                                                                                                   |
| **사후 조건**    | 최신 작업 진행 상태가 저장되고 관리자와 기사에게 반영된다. 작업 완료는 UC-12의 최초 보고서 제출이 정상 저장된 시점에 확정된다. 작성 취소·미제출·제출 실패 시 작업을 완료로 변경하지 않으며, 보고서 저장과 작업 완료 중 일부만 반영되지 않아야 한다. |
