# UC-03 의뢰 등록 및 배차 요청

| 항목           | 내용                                                                                                                                                                                                                                                                                       |
|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                                                                                                                                                      |
| **유스케이스 내용** | 관리자가 검토한 상담 접수 정보를 의뢰로 확정하고 시스템이 출동 가능한 기사에게 배차 요청을 전달한다.                                                                                                                                                                                                                                |
| **사전 조건**    | 1. 관리자가 로그인되어 있어야 한다.<br>2. 접수에 필요한 정보에 대한 관리자 검토가 완료되어 있어야 한다.                                                                                                                                                                                                                          |
| **기본 흐름**    | 1. 관리자가 최종 접수 정보를 확인한다.<br>2. 관리자가 의뢰 등록을 선택한다.<br>3. 시스템이 의뢰를 생성한다.<br>4. 시스템이 [FR-05](../functional-requirements/fr-05-request-registration-and-dispatch-candidate-selection.md)에 따라 활성 계정인 기사 중 작업 유형, 작업 가능 상태, 전문 분야(외벽누수, 내벽누수, 막힘), 활동 지역, 유효한 최신 위치정보 및 진행 중 작업 여부 등의 조건을 만족하는 후보를 선별한다. 유효하지 않은 위치정보는 거리 기반 후보 선정에 사용하지 않는다.<br>5. 시스템이 선별된 기사에게 배차 요청을 전달한다.<br>6. 시스템이 의뢰를 배차 진행 상태로 변경한다. |
| **예외 흐름**    | E1. 필수 접수 정보가 누락된 경우 → 시스템이 의뢰 등록을 제한하고 누락 정보를 안내한다.<br>E2. 설정된 탐색 종료 조건에 도달할 때까지 적합한 기사 후보를 찾지 못한 경우 → 시스템은 탐색을 종료하고 관리자에게 배차 가능한 기사가 없음을 안내한다. 관리자는 대안 흐름 A1에 따라 후속 배차를 진행한다.<br>E3. 배차 요청 전달에 실패한 경우 → 시스템이 해당 상태를 기록하고 관리자에게 안내한다. |
| **대안 흐름**    | A1. 자동으로 적합한 기사 후보를 확보하지 못한 경우 → 관리자가 상황을 확인하고 후속 배차를 진행한다.<br>A2. 초기 탐색 범위에서 적합한 기사 후보가 없는 경우 → 시스템은 설정된 배차 정책에 따라 탐색 범위를 확대하여 후보를 다시 탐색한다. |
| **사후 조건**    | 의뢰가 등록되고 출동 가능한 기사에 대한 배차 절차가 시작된다.                                                                                                                                                                                                                                                      |
| **설계 시 고려사항** | 초기 탐색 반경, 확대 단위, 최대 반경, 타임아웃 및 탐색 종료 조건의 구체적인 수치는 추후 결정한다. |
