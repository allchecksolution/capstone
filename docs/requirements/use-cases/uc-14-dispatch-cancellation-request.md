# UC-14 배차 취소 요청

| 항목           | 내용                                                                                                                                                                                                    |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                                    |
| **유스케이스 내용** | 배차를 수락한 기사가 불가피한 사유로 해당 작업을 수행할 수 없는 경우 배차 취소를 요청한다.                                                                                                                                                  |
| **사전 조건**    | 1. 기사가 로그인되어 있어야 한다.<br>2. 해당 기사가 의뢰를 수락하여 담당 기사로 배정되어 있어야 한다.                                                                                                                                        |
| **기본 흐름**    | 1. 기사가 배정된 의뢰를 조회한다.<br>2. 기사가 배차 취소 요청을 선택한다.<br>3. 시스템이 취소 사유 입력을 요청한다.<br>4. 기사가 취소 사유를 입력하고 요청을 제출한다.<br>5. 시스템이 배차 취소 요청을 저장한다.<br>6. 시스템이 관리자에게 배차 취소 상황을 표시한다.<br>7. 해당 의뢰는 재배차가 필요한 상태로 변경된다. |
| **예외 흐름**    | E1. 이미 취소되거나 종료된 의뢰인 경우 → 시스템이 취소 요청을 제한한다.<br>E2. 취소 요청 처리에 실패한 경우 → 시스템이 오류를 안내한다.                                                                                                                  |
| **대안 흐름**    | A1. 취소 요청 전에 기사와 관리자가 [UC-17](./uc-17-admin-driver-chat.md)의 1:1 채팅을 통해 상황을 확인할 수 있다.                                                                                                                 |
| **사후 조건**    | 배차 취소 요청이 기록되고 해당 의뢰가 관리자 확인 또는 재배차가 필요한 상태가 된다.                                                                                                                                                      |
