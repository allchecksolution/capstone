# UC-17 관리자·기사 1:1 채팅

| 항목           | 내용                                                                                                                                                                                            |
|--------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자, 기사                                                                                                                                                                                       |
| **유스케이스 내용** | 관리자와 기사가 기사별 1:1 채팅을 통해 배차, 작업 및 현장 상황 등에 필요한 정보를 지속적으로 주고받는다.                                                                                                                                |
| **사전 조건**    | 1. 관리자 또는 기사가 로그인되어 있어야 한다.<br>2. 관리자와 해당 기사 사이에 채팅이 가능한 관계가 형성되어 있어야 한다.<br>3. 대화 대상 기사 계정 상태가 '활성'이어야 한다. 이 조건은 관리자와 기사 모두의 채팅방 진입·대화 이력 조회·메시지 전송에 동일하게 적용하며, 시스템은 각 요청 처리 시 현재 상태를 확인한다. '승인 대기', '반려', '탈퇴' 상태이면 세 기능을 모두 거부하고, 기존 연결에서도 메시지마다 이를 확인한다.                                                                                                                     |
| **기본 흐름**    | 1. 관리자 또는 기사가 1:1 채팅 화면에 진입한다.<br>2. 시스템이 기존 대화 내역을 표시한다.<br>3. 사용자가 메시지를 입력하고 전송한다.<br>4. 시스템이 메시지를 저장한다.<br>5. 시스템이 상대방에게 새로운 메시지를 전달한다.<br>6. 상대방이 메시지를 확인한다.<br>7. 관리자와 기사가 필요한 대화를 계속한다. |
| **예외 흐름**    | E1. 메시지 전송에 실패한 경우 → 시스템이 전송 실패 상태를 표시하고 재전송할 수 있도록 한다.<br>E2. 네트워크 연결이 불안정한 경우 → 시스템이 연결 상태 또는 메시지 전송 실패를 안내한다.                                                                              |
| **대안 흐름**    | A1. 상대방이 채팅 화면을 사용하고 있지 않은 경우 → 시스템이 새로운 메시지가 도착했음을 알림으로 전달한다.                                                                                                                                |
| **사후 조건**    | 송수신된 메시지가 대화 이력으로 저장되며 관리자와 기사는 사전 조건(대화 대상 기사 계정의 '활성' 상태 포함)을 충족하는 경우에만 이후 다시 확인할 수 있다.                                                                                                                                               |
