# UC-02 AI 접수 정보 검토 및 수정

| 항목           | 내용                                                                                                                                                                                                             |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                                                                            |
| **유스케이스 내용** | 전화 상담 내용을 기반으로 AI가 추출한 주요 접수 정보를 관리자가 확인하고 필요한 경우 수정한다.                                                                                                                                                        |
| **사전 조건**    | 1. 관리자가 로그인되어 있어야 한다.<br>2. 상담 접수가 등록되어 있어야 한다.<br>3. AI 분석 결과가 존재하거나, 녹음 수집·STT·AI 처리 실패 상태가 기록되어 있어야 한다. |
| **기본 흐름**    | 1. 관리자가 상담 접수 상세 화면을 조회한다.<br>2. 시스템은 상담 녹음 원본, STT 결과 및 AI 분석 결과가 실제로 존재하는 경우에만 해당 자료를 표시한다. 분석 결과가 없는 경우 예외 흐름 E1의 관리자 수동 입력으로 연결한다.<br>3. 관리자가 작업 유형, 증상, 주소, 방문 희망시간 등 추출된 정보를 확인한다.<br>4. 잘못 추출된 정보가 있는 경우 관리자가 해당 정보를 수정한다.<br>5. 관리자가 검토 완료를 선택한다.<br>6. 시스템이 최종 확인된 접수 정보를 저장한다. |
| **예외 흐름**    | E1. 상담 녹음 파일 확보, STT 처리 또는 AI 분석에 실패한 경우 → 시스템이 실패 상태를 표시하고 관리자가 접수 정보를 수동 입력한 뒤 기본 흐름 5~6의 검토 완료 및 최종 확정 저장 절차를 진행한다. 필수 접수 정보가 누락되면 E2에 따라 보완한 후 확정한다.<br>E2. 필수 접수 정보가 누락된 경우 → 시스템이 누락 항목을 안내하고, 해당 정보가 보완되기 전까지 최종 확정 저장을 제한한다. |
| **대안 흐름**    | A1. AI가 추출한 정보가 모두 정확한 경우 → 관리자는 별도 수정 없이 검토를 완료한다.                                                                                                                                                            |
| **사후 조건**    | 관리자에 의해 확인된 접수 정보가 저장되며 의뢰 등록에 사용할 수 있다.                                                                                                                                                                       |
