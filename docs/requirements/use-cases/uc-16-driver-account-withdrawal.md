# UC-16 기사 회원 탈퇴

| 항목           | 내용                                                                                                                                                                                        |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 기사                                                                                                                                                                                        |
| **유스케이스 내용** | 기사가 더 이상 서비스를 이용하지 않을 경우 본인의 계정을 탈퇴 처리한다.                                                                                                                                                 |
| **사전 조건**    | 1. 기사가 로그인되어 있어야 한다.                                                                                                                                                                      |
| **기본 흐름**    | 1. 기사가 개인 정보 및 환경 설정 화면에서 계정 탈퇴를 선택한다.<br>2. 시스템이 탈퇴 시 유의사항(진행 중인 작업이 있는 경우 탈퇴 불가 등)을 안내한다.<br>3. 기사가 탈퇴를 최종 확인한다.<br>4. 시스템이 기사 계정을 탈퇴 처리한다.<br>5. 시스템이 이후 로그인 및 배차 후보 선정에서 해당 기사를 제외한다. |
| **예외 흐름**    | E1. 진행 중인(배정된) 작업이 있는 경우 → 시스템이 탈퇴를 제한하고 사유를 안내한다.<br>E2. 탈퇴 처리 중 오류가 발생한 경우 → 시스템이 오류를 안내하고 계정을 유지한다.                                                                                    |
| **대안 흐름**    | 없음                                                                                                                                                                                        |
| **사후 조건**    | 기사 계정이 탈퇴 처리되며 이후 로그인 및 신규 배차 대상에서 제외된다.<br>1. 통계 목적으로 보존할 필드는 작업 식별자, 가명 기사 식별자, 작업 유형, 완료 월, 작업 결과 상태, 작업 비용으로 제한하고, 탈퇴일로부터 1년간 보존한 뒤 삭제한다.<br>2. 기사 식별자는 무작위 가명값으로 대체하며, 계정과의 대응표는 분리 저장하고 개인정보 관리 권한이 있는 관리자만 접근할 수 있다. 대응표도 같은 기한에 삭제한다.<br>3. 이력과 연결된 보고서 원본·수정 이력, 첨부 파일, 자유 입력 내용에 포함된 기사·고객의 이름·전화번호·이메일 등 직접 식별정보와 주소·좌표·이동 경로 등 상세 위치정보는 탈퇴 시 삭제하거나 복원할 수 없도록 제거한다. 해당 정보를 제거할 수 없는 자료는 보존 대상에서 제외하고 삭제한다.<br>4. 가명 처리된 이력은 통계 조회 권한이 있는 관리자만 조회·내보낼 수 있으며, 화면·내보내기·로그에 실명과 연락처·상세 위치가 노출되지 않도록 제거하고 가명 식별자는 기본 마스킹한다. 기사별 통계도 가명값으로만 제공하며 대응표 접근은 통계 조회 권한과 분리한다.<br>5. 1년 만료 시 이력과 대응표를 운영 저장소·복제본·백업에서 복원할 수 없도록 삭제하며, 탈퇴 시 제거한 개인정보도 백업 복원으로 다시 노출되지 않도록 삭제 또는 비식별 처리를 적용한다. 이 기준은 작업 보고서의 원본·수정 이력 보존에도 적용한다.                                                                                                               |
