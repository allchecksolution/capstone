# UC-01 관리자 로그인 및 MFA 인증

| 항목           | 내용                                                                                                                                                                        |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **행위자**      | 관리자                                                                                                                                                                       |
| **유스케이스 내용** | 사전에 등록된 관리자 계정으로 로그인하고 MFA 추가 인증을 수행하여 관리자 시스템에 접근한다.                                                                                                                     |
| **사전 조건**    | 1. 관리자 계정이 사전에 시스템에 등록되어 있어야 한다.(마스터 관리자 또는 부 관리자, `role`로 구분).<br>2. 관리자 계정에 MFA가 설정되어 있어야 한다.(최초 로그인 시에는 대안 흐름 A1을 따른다).                                                |
| **기본 흐름**    | 1. 관리자가 아이디와 비밀번호를 입력한다.<br>2. 시스템이 입력된 계정 정보를 확인한다.<br>3. 시스템이 MFA 인증을 요청한다.<br>4. 관리자가 인증 앱에 표시된 인증 코드를 입력한다.<br>5. 시스템이 MFA 인증 코드를 검증한다.<br>6. 인증에 성공하면 관리자 로그인이 완료된다. |
| **예외 흐름**    | E1. 아이디 또는 비밀번호가 일치하지 않는 경우 → 시스템이 로그인 실패를 안내한다.<br>E2. MFA 인증 코드가 올바르지 않은 경우 → 시스템이 인증 실패를 안내하고 재입력을 요청한다.<br>E3. MFA 인증 코드의 유효시간이 만료된 경우 → 새로운 인증 코드 입력을 요청한다.          |
| **대안 흐름**    | A1. 최초 로그인으로 계정에 MFA가 아직 설정되지 않은 경우 → 1차 인증(ID/PW) 성공 후 시스템이 TOTP 등록 절차(인증 앱 등록용 QR/시크릿 제공)를 안내하고, 관리자가 등록을 완료하면 이후 흐름을 계속 진행한다.                                          |
| **사후 조건**    | 관리자가 인증된 상태가 되며 관리자 기능에 접근할 수 있다. 마스터/부 관리자 모두 이 절차로 인증되며, 역할(`role`)에 따른 세부 기능 접근 범위 차이는 별도 정책으로 확정되지 않아 현재는 두 역할 모두 동일한 관리자 기능에 접근한다.                                   |
