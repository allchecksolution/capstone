# FR-03 AI 기반 상담 정보 분석 및 구조화

| 항목            | 내용                                                                                                                                                                                                                                                             |
|---------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 시스템 / AI                                                                                                                                                                                                                                                       |
| **요구사항 명칭**   | AI 기반 상담 정보 분석 및 구조화                                                                                                                                                                                                                                           |
| **정의**        | STT로 변환된 상담 내용을 AI가 분석하여 서비스 접수 및 배차에 필요한 주요 정보를 구조화해야 한다.                                                                                                                                                                                                     |
| **세부 내용**     | 1. 시스템은 STT 결과를 AI 분석 대상으로 전달해야 한다.<br>2. AI는 상담 내용에서 작업 유형, 증상, 주소, 방문 희망 일정 및 특이사항 등의 정보를 추출해야 한다.<br>3. AI 분석 결과를 시스템이 처리 가능한 정해진 데이터 구조로 반환해야 한다.<br>4. AI 분석 결과와 STT 원문을 함께 관리자가 확인할 수 있도록 제공해야 한다.<br>5. AI 분석에 실패한 경우 실패 상태를 기록하고 관리자가 확인할 수 있도록 해야 한다.<br>6. 녹음 업로드 완료 후 분석을 자동 시작하고, 원문 보관 후 구조화 분석을 수행해야 한다.<br>7. 완료·실패를 관리자에게 푸시로 알리고 서버에서 최신 결과를 조회할 수 있어야 한다.<br>8. MVP에서는 최초 분석만 수행하며, 오류·누락 정보는 관리자 수정·수동 입력으로 보완한다. 재분석은 제공하지 않는다. |
| **설계 시 고려사항** | AI Service와 Backend 간 API 인터페이스 정의<br>구조화된 JSON 형태의 분석 결과 사용<br>AI 분석 결과는 최종 확정 정보가 아닌 관리자 검토 대상으로 처리                                                                                                                                                          |
| **관련 유스케이스**  | [UC-02 AI 분석 결과 검토 및 수정](../use-cases/uc-02-ai-reception-review.md)                                                                                                                                                                                            |

업무 정책은 [BR-09](../../../apps/backend/docs/business-specification.md#br-09), AI 요청·응답은 [AI OpenAPI](../../../apps/ai/docs/openapi.yaml)를 따른다.

검토 화면의 최초 AI 결과 자동 채움과 관리자 저장값 보호는 [BR-04](../../../apps/backend/docs/business-specification.md#br-04)를 따른다.
작업 유형은 막힘·외벽 누수·내벽 누수·보일러·방수 5개이며, 관리자 검토·의뢰·기사 전문 분야에도 같은 분류를 사용한다.
현재 AI 추출 계약에는 연락처가 포함되지 않는다. 연락처 자동 확보 방법은 프런트 검토 과제이며, 확정 시 연락처 필수 검증과 구분한다.
