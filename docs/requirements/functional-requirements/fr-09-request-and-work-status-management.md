# FR-09 의뢰 및 작업 진행 상태 관리

| 항목            | 내용                                                                                                                                                                                                                                                                                                                                                            |
|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 관리자 / 기사                                                                                                                                                                                                                                                                                                                                                      |
| **요구사항 명칭**   | 의뢰 및 작업 진행 상태 관리                                                                                                                                                                                                                                                                                                                                              |
| **정의**        | 관리자와 기사가 의뢰의 배차 및 작업 진행 상태를 확인하고, 기사가 작업 진행 상황에 따라 상태를 변경할 수 있어야 한다.                                                                                                                                                                                                                                                                                          |
| **세부 내용**     | 1. 관리자는 등록된 의뢰 목록과 현재 진행 상태를 조회할 수 있어야 한다.<br>2. 관리자는 배차 상태와 담당 기사를 확인할 수 있어야 한다.<br>3. 기사는 자신에게 배정된 의뢰의 작업 상태를 변경할 수 있어야 한다.<br>4. 시스템은 작업 시작·완료 등의 상태 변경을 저장해야 한다.<br>5. 기사에 의해 변경된 작업 상태를 관리자 화면에도 반영해야 한다.<br>6. 시스템은 작업 상태 변경 시 현재 상태와 변경하려는 상태를 기준으로 허용된 상태 전이인지 검증해야 하며, 허용되지 않은 상태 변경을 거부해야 한다.<br>7. 작업이 완료되지 않고 추가 방문이 필요한 경우 재방문 상태를 관리할 수 있어야 한다. |
| **설계 시 고려사항** | 의뢰 상태와 작업 상태의 명확한 상태 전이 정의<br>상태 변경 시각 및 변경 이력 저장<br>실시간 상태 반영 방식 적용<br>구체적인 상태 전이 규칙과 예외적인 상태 보정 정책은 작업 진행 및 취소·재배차 흐름을 고려하여 정의한다. [UC-12](../use-cases/uc-12-work-status-update.md) 및 [FR-12](./fr-12-dispatch-cancellation-and-redispatch-management.md)과 상태 명칭 및 처리 기준을 일치시킨다.                                                                            |
