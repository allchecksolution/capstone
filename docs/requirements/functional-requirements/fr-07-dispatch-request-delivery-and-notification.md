# FR-07 배차 요청 및 알림

| 항목            | 내용                                                                                                                                                                                                                                                      |
|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 시스템 / 기사                                                                                                                                                                                                                                                |
| **요구사항 명칭**   | 배차 요청 전달 및 알림                                                                                                                                                                                                                                           |
| **정의**        | 시스템은 배차 후보로 선정된 기사에게 신규 배차 요청을 전달하고 기사가 이를 확인할 수 있도록 해야 한다.                                                                                                                                                                                             |
| **세부 내용**     | 1. 시스템은 선별된 기사에게 배차 요청을 생성해야 한다.<br>2. 기사에게 신규 배차 요청 발생 사실을 Push Notification으로 전달해야 한다.<br>3. 기사는 자신에게 전달된 요청을 확인할 수 있어야 한다.<br>4. 기사는 작업 유형, 증상, 작업 위치 및 방문 관련 정보 등 배차 판단에 필요한 정보를 확인할 수 있어야 한다.<br>5. 이미 종료되거나 다른 기사에게 배정된 요청은 유효하지 않은 요청으로 처리해야 한다. |
| **설계 시 고려사항** | FCM 기반 Push Notification 활용<br>Push Notification 자체가 의뢰 데이터의 원본이 되지 않도록 하고 앱에서 서버의 최신 배차정보 조회                                                                                                                                                           |
| **관련 유스케이스**  | [UC-03 의뢰 등록](../use-cases/uc-03-dispatch-request.md), [UC-11 배차 요청 수락 및 거절](../use-cases/uc-11-dispatch-request-response.md)                                                                                                                           |
