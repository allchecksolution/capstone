# FR-11 작업 보고서 등록 및 관리

| 항목            | 내용                                                                                                                                                                                                                                                                                            |
|---------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 기사 / 관리자                                                                                                                                                                                                                                                                                      |
| **요구사항 명칭**   | 작업 보고서 등록 및 관리                                                                                                                                                                                                                                                                                |
| **정의**        | 기사가 수행한 작업의 내용과 결과를 보고서로 등록하고 관리자가 이를 조회 및 관리할 수 있어야 한다.                                                                                                                                                                                                                                      |
| **세부 내용**     | 1. 기사는 자신에게 배정된 작업에 대한 보고서를 작성할 수 있어야 한다.<br>2. 작업 전·후 사진을 등록할 수 있어야 한다.<br>3. 작업 내용, 진단 결과, 작업 비용 등의 정보를 입력할 수 있어야 한다.<br>4. 시스템은 보고서를 해당 의뢰 및 담당 기사와 연결하여 저장해야 한다.<br>5. 관리자는 기사가 제출한 작업 보고서를 조회할 수 있어야 한다.<br>6. 관리자는 권한이 허용된 보고서 정보를 수정할 수 있어야 한다.<br>7. 시스템은 제출 당시의 원본(작업 전·후 사진 포함)을 변경 없이 보존하고, 관리자 수정 이력을 원본과 별도로 누적 저장해야 한다. 각 이력에는 변경 항목의 수정 전·후 값, 수정자, 수정 시각 및 승인 상태('승인 대기', '승인', '반려')를 기록해야 한다.<br>8. 수정본은 '승인 대기'로 저장하며, 승인 권한이 있는 관리자의 승인 또는 반려 결과와 처리자·처리 시각을 기록해야 한다. 승인된 수정본을 다시 수정할 경우 새 이력으로 저장해야 한다.<br>9. 작업 이력 조회 및 통계 산정에는 가장 최근 승인된 수정본을 사용하고, 승인된 수정본이 없으면 제출 원본을 사용해야 한다. 승인 대기·반려된 수정값은 반영하지 않으며, 원본과 전체 수정 이력은 별도로 추적할 수 있어야 한다.<br>10. 기사 탈퇴 시에는 [UC-16](../use-cases/uc-16-driver-account-withdrawal.md)의 개인정보 제거 및 보존 기간·파기 기준을 원본과 수정 이력에도 적용한다. |
| **설계 시 고려사항** | 이미지 파일 저장소와 DB 메타데이터 분리 고려<br>작업 보고서 원본·수정 이력 분리 저장 및 승인 상태별 조회·집계 기준 적용                                                                                                                                                                                                                                   |
| **관련 유스케이스**  | [UC-05 기사 작업 보고서 조회 및 수정](../use-cases/uc-05-work-report-review.md), [UC-13 작업 보고서 등록](../use-cases/uc-13-work-report-submission.md)                                                                                                                                                          |
