# FR-08 배차 요청 수락 및 거절

| 항목            | 내용                                                                                                                                                                                                                                              |
|---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 기사 / 시스템                                                                                                                                                                                                                                        |
| **요구사항 명칭**   | 배차 요청 수락·거절 및 미배정 작업 수락                                                                                                                                                                                                                         |
| **정의**        | 기사는 자신에게 전달된 배차 요청을 수락 또는 거절할 수 있다. 시스템은 수락 결과에 따라 담당 기사를 확정해야 한다.                                                                                                                                                                              |
| **세부 내용**     | 1. 기사는 자신에게 전달된 유효한 배차 요청을 수락 또는 거절할 수 있어야 한다.<br>2. 기사는 미배정 작업의 상세정보를 확인할 수 있어야 한다.<br>3. 동일 작업에 여러 기사가 동시에 수락을 요청하더라도 한 명의 기사만 담당 기사로 확정되어야 한다.<br>6. 담당 기사가 확정되면 해당 작업에 대한 다른 기사의 배차 요청을 종료한다.<br>7. 시스템은 담당 기사 확정 결과를 해당 기사와 관리자에게 반영해야 한다. |
| **설계 시 고려사항** | 동시 수락에 대한 원자적 처리 및 동시성 제어 필요<br>배차 요청·수락·거절·취소·재배차에 대한 상태 및 이력 관리 필요                                                                                                                                                                            |
