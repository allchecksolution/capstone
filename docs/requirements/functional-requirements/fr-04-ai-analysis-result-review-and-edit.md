# FR-04 AI 분석 결과 검토 및 수정

| 항목            | 내용                                                                                                                                                                                                                                                                            |
|---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 관리자                                                                                                                                                                                                                                                                           |
| **요구사항 명칭**   | AI 분석 결과 검토 및 수정                                                                                                                                                                                                                                                              |
| **정의**        | 관리자가 상담 녹음, STT 결과 및 AI가 추출한 접수 정보를 비교하고 잘못된 정보를 수정하여 최종 접수 정보를 확정할 수 있어야 한다.                                                                                                                                                                                                 |
| **세부 내용**     | 1. 관리자는 상담 녹음 원본이 존재하는 경우 이를 확인할 수 있어야 한다.<br>2. 관리자는 STT 결과가 존재하는 경우 변환된 상담 내용을 확인할 수 있어야 한다.<br>3. 관리자는 AI 분석 결과가 존재하는 경우 추출된 작업 유형, 증상, 주소, 방문 희망시간 등의 정보를 확인할 수 있어야 한다.<br>4. 잘못 추출되거나 누락된 정보를 관리자가 수정할 수 있어야 한다.<br>5. 관리자는 검토한 접수 정보를 최종 확정할 수 있어야 한다.<br>6. 시스템은 관리자가 최종 확정한 정보를 의뢰 등록에 사용할 수 있도록 저장해야 한다.<br>7. 녹음 수집·STT·AI 분석 실패 시에도 관리자가 접수 정보를 수동 입력하고 동일한 검토 완료 및 최종 확정 저장 절차를 진행할 수 있어야 한다. |
| **설계 시 고려사항** | AI 원본 분석 결과와 관리자 수정 결과를 구분하여 관리하는 방안 고려<br>필수 접수정보에 대한 입력값 검증 적용                                                                                                                                                                                                              |
