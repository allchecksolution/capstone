# FR-05 의뢰 등록 및 배차 후보 선별

| 항목            | 내용                                                                                                                                                                                                                                                                                                                                    |
|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 관리자 / 시스템                                                                                                                                                                                                                                                                                                                             |
| **요구사항 명칭**   | 의뢰 등록 및 배차 후보 선별                                                                                                                                                                                                                                                                                                                      |
| **정의**        | 관리자가 검토한 접수정보를 의뢰로 등록하면 시스템이 의뢰 조건과 기사 정보를 기반으로 출동 가능한 기사 후보를 선별해야 한다.                                                                                                                                                                                                                                                                |
| **세부 내용**     | 1. 관리자는 검토가 완료된 접수정보를 의뢰로 등록할 수 있어야 한다.<br>2. 시스템은 작업 유형과 기사의 전문 분야를 비교해야 한다.<br>3. 시스템은 기사의 작업 가능 상태를 확인해야 한다.<br>4. 시스템은 기사의 활동 지역 및 최신 위치정보를 배차 후보 선정에 활용해야 한다.<br>5. 시스템은 현재 작업을 진행중인 기사를 배차 후보에서 제외해야 한다.<br>6. 위 내용을 포함한 배차 조건을 만족하는 기사 후보를 선별해야 한다.<br>7. 출동 가능한 기사가 없는 경우 관리자에게 해당 상태를 제공해야 한다.<br>8. 등록된 의뢰의 배차 상태를 관리해야 한다. |
| **설계 시 고려사항** | 작업 가능 상태·전문 분야·활동 지역·GPS 위치를 기반으로 후보 선별<br>향후 평점·작업 성공률·작업 이력 등을 활용한 배차 우선순위 고도화 가능하도록 데이터 축적                                                                                                                                                                                                                                         |
| **관련 유스케이스**  | [UC-03 의뢰 등록](../use-cases/uc-03-dispatch-request.md)                                                                                                                                                                                                                                                                                 |
