# FR-02 상담 녹음 자동 수집 및 STT 변환

| 항목            | 내용                                                                                                                                                                                                                                                                                                          |
|---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 시스템                                                                                                                                                                                                                                                                                                         |
| **요구사항 명칭**   | 상담 녹음 자동 수집 및 STT 변환                                                                                                                                                                                                                                                                                        |
| **정의**        | 고객과 관리자의 전화 상담 종료 후 생성된 녹음 파일을 시스템이 자동으로 확보하고 STT를 통해 텍스트로 변환해야 한다.                                                                                                                                                                                                                                         |
| **세부 내용**     | 1. 전화 상담 종료 후 생성된 녹음 파일을 자동으로 확보할 수 있어야 한다.<br>2. 확보한 녹음 파일을 상담 건과 연결하여 저장할 수 있어야 한다.<br>3. 시스템은 녹음 파일을 STT 서비스에 전달하여 상담 내용을 텍스트로 변환해야 한다.<br>4. STT 변환 결과를 원본 녹음 파일과 함께 저장해야 한다.<br>5. 녹음 파일 확보 또는 STT 처리에 실패한 경우 실패 상태를 기록하고 관리자가 확인할 수 있어야 한다.<br>6. 녹음 파일 자동 수집 또는 STT 처리가 불가능한 경우, 관리자가 상담 접수 정보를 직접 입력할 수 있는 수단을 제공해야 한다. |
| **설계 시 고려사항** | 상담 녹음 파일 자동 수집 방식 및 연동 대상 시스템 확인 필요<br>자동 수집 가능 여부는 추후 PoC를 통해 검증하며, 결과에 따라 수집 방식 및 지원 범위가 변경될 수 있음<br>STT 서비스 연동 방식 및 실제 녹음 품질에 대한 정확도 검증 필요<br>녹음 원본과 STT 결과의 연결 관계 유지<br>녹음 파일 수동 업로드 기능 제공 여부는 추후 결정하며, 수동 접수 정보 입력과 구분 |
