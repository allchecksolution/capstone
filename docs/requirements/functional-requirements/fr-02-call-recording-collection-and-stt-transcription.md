# FR-02 상담 녹음 자동 수집 및 STT 변환

| 항목            | 내용                                                                                                                                                                                                                                                                                                          |
|---------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 시스템                                                                                                                                                                                                                                                                                                         |
| **요구사항 명칭**   | 상담 녹음 자동 수집 및 STT 변환                                                                                                                                                                                                                                                                                        |
| **정의**        | 고객과 관리자의 전화 상담 종료 후 생성된 녹음 파일을 시스템이 자동으로 확보하고 STT를 통해 텍스트로 변환해야 한다.                                                                                                                                                                                                                                         |
| **세부 내용**     | 1. 전화 상담 종료 후 생성된 녹음 파일을 자동으로 확보할 수 있어야 한다.<br>2. 확보한 녹음 파일을 상담 건과 연결하여 저장할 수 있어야 한다.<br>3. 시스템은 녹음 파일을 STT 서비스에 전달하여 상담 내용을 텍스트로 변환해야 한다.<br>4. STT 변환 결과를 원본 녹음 파일과 함께 저장해야 한다.<br>5. 녹음 파일 확보 또는 STT 처리에 실패한 경우 실패 상태를 기록하고 관리자가 확인할 수 있어야 한다.<br>6. 녹음 파일 자동 수집 또는 STT 처리가 불가능한 경우, 관리자가 상담 접수 정보를 직접 입력할 수 있는 수단을 제공해야 한다. |
| **설계 시 고려사항** | 관리자 앱이 녹음을 S3에 업로드하고 완료를 알리면 Backend가 검증 후 최초 분석을 자동 시작한다.<br>녹음과 STT 원문은 S3에 보관하고 접수와의 연결·처리 상태는 Backend가 관리한다.<br>MVP는 접수당 녹음 1개이며 완료 전 업로드 재시도는 지원하고 원본 교체는 제외한다.<br>모바일의 실제 녹음 확보·자동 수집 가능 여부 및 수동 파일 선택 UI는 PoC로 검증한다. 수동 접수 정보 입력과 구분한다. |
| **관련 유스케이스**  | [UC-02 AI 분석 결과 검토 및 수정](../use-cases/uc-02-ai-reception-review.md)의 선행 시스템 기능                                                                                                                                                                                                                              |

상세 업무 정책은 [BR-09](../../../apps/backend/docs/business-specification.md#br-09), 요청·응답은 [Backend OpenAPI](../../api/openapi.yaml)를 따른다.
