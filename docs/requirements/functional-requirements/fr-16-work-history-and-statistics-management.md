# FR-16 작업 이력 및 통계 관리

| 항목            | 내용                                                                                                                                                                                                                                                                              |
|---------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 관리자                                                                                                                                                                                                                                                                             |
| **요구사항 명칭**   | 과거 작업 이력 및 통계 조회                                                                                                                                                                                                                                                                |
| **정의**        | 관리자가 시스템에 축적된 의뢰·배차·작업 데이터를 조회하고 운영 및 향후 배차 고도화에 활용할 수 있어야 한다.                                                                                                                                                                                                                  |
| **세부 내용**     | 1. 관리자는 과거 의뢰 및 작업 이력을 조회할 수 있어야 한다.<br>2. 기간, 기사, 작업 유형, 작업 상태 등의 조건을 이용하여 데이터를 조회할 수 있어야 한다.<br>3. 기사별 작업 수행 이력을 조회할 수 있어야 한다.<br>4. 작업 완료·취소·재방문 등 주요 결과 데이터를 누적 관리해야 한다.<br>5. 시스템은 축적된 데이터를 통계 형태로 제공할 수 있어야 한다.<br>6. 필요 시 조회 결과를 스프레드시트 등의 외부 형식으로 내보낼 수 있도록 확장 가능해야 한다. |
| **설계 시 고려사항** | 향후 평점·작업 성공률·작업 이력 등을 활용한 배차 우선순위 고도화가 가능하도록 데이터 구조 설계<br>통계 데이터와 운영 원본 데이터 구분 고려<br>작업 보고서 기반 조회·통계는 [FR-11](./fr-11-work-report-registration-and-management.md)의 최신 유효 수정 내용 반영 기준을 따르며, 기사 탈퇴 관련 데이터는 [UC-16](../use-cases/uc-16-driver-account-withdrawal.md)의 접근 통제 및 보존·파기 정책을 따른다. |
| **관련 유스케이스**  | [UC-08 과거 작업 이력 및 통계 조회](../use-cases/uc-08-work-history-statistics-inquiry.md)                                                                                                                                                                                                 |
