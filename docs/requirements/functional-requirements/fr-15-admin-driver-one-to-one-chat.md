# FR-15 관리자-기사 1:1 채팅

| 항목            | 내용                                                                                                                                                                                                                                                                 |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **요구사항 유형**   | 공통                                                                                                                                                                                                                                                                 |
| **요구사항 명칭**   | 관리자-기사 간 1:1 채팅                                                                                                                                                                                                                                                    |
| **정의**        | 관리자와 기사가 배차, 작업 및 현장 상황 등에 필요한 정보를 기사별 1:1 채팅을 통해 실시간으로 주고받을 수 있어야 한다.                                                                                                                                                                                             |
| **세부 내용**     | 1. 기사별로 관리자와 지속적인 1:1 채팅을 제공해야 한다<br>2. 관리자와 기사는 텍스트 메시지를 송수신할 수 있어야 한다.<br>3. 시스템은 채팅 메시지를 저장하고 기존 대화 내역을 조회할 수 있도록 해야 한다.<br>4. 새로운 메시지를 상대방에게 실시간으로 전달해야 한다.<br>5. 실시간 연결이 불가능한 경우 상대방이 새로운 메시지를 인지할 수 있도록 알림을 제공해야 한다.<br>6. 메시지 전송 실패 시 실패 상태를 사용자에게 제공해야 한다.<br>7. 정상적인 채팅 이용과 메시지 전송은 활성 기사와의 대화에만 허용하고, 전송 시 기사 계정 상태와 채팅 권한을 확인해야 한다. 승인 대기·반려·탈퇴 기사의 일반 채팅 접근과 해당 대화의 새로운 메시지 전송은 제한해야 한다.<br>8. 권한 있는 관리자는 비활성 기사와의 과거 대화를 읽기 전용으로 조회할 수 있어야 하며, 대화 이력의 접근 통제 및 보존·파기는 [UC-15](../use-cases/uc-15-driver-account-withdrawal.md)을 따른다.<br>9. 메시지 전송 실패 또는 결과 확인 불가 시 재전송을 허용하되, 동일한 전송 요청으로 메시지가 중복 저장되지 않아야 한다. |
| **설계 시 고려사항** | WebSocket 기반 실시간 양방향 통신<br>기사별 지속적인 채팅방 관리<br>비접속 사용자에 대한 Push Notification 연계 고려                                                                                                                                                                                  |
| **관련 유스케이스**  | [UC-16 기사-관리자 간 1:1 채팅](../use-cases/uc-16-admin-driver-chat.md)                                                                                                                                                                                                   |
