# 공통 자료 목록

이 문서는 팀이 사용하는 자료의 **공식 위치를 찾는 목차**입니다. 문서의 내용을 이곳에 중복해서 적지 않고 원본으로 연결합니다.

| 자료 | 공식 위치 | 담당자 | 상태 |
| --- | --- | --- | --- |
| 요구사항 | [requirements.md](requirements.md) | 미정 | 작성 전 |
| 화면 설계 | [screen-design.md](screen-design.md) | 미정 | 작성 전 |
| 팀 작업 방법 | [TEAM_GUIDE.md](TEAM_GUIDE.md) | 팀 전체 | 초안 |

외부 자료를 추가할 때는 아래 형식으로 행을 추가합니다. 비공개 링크라면 팀원 모두에게 열람 권한을 부여했는지 확인합니다.

| 자료 | 공식 위치 | 담당자 | 상태 |
| --- | --- | --- | --- |
| 예: 디자인 원본 | 공유 URL | 담당자 이름 | 초안 / 검토 중 / 확정 |

자료의 위치가 바뀌거나 공식 버전이 수정되면 이 목록과 연결된 문서를 같은 Pull Request에서 갱신합니다.
